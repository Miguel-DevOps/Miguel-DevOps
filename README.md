### 🚀 The Mission: Capital Efficiency & Sovereignty

I help engineering teams make **deliberate infrastructure decisions**, choosing the right tool for the job, whether that's a hyperscaler, bare metal, or a hybrid approach, with a **focus on perimeter security, cost efficiency, observability, and data sovereignty**.

My engineering philosophy is **"Boring is Better"**: I reject unnecessary complexity in favor of robust, maintainable, and cost-effective architectures that you can actually debug at 3:00 AM. That includes Kubernetes: in an early-stage company, SaaS or project without real revenue it is overhead, and at scale it stops being a choice and becomes the right answer. I run both and pick by stage, not by fashion.

#### 🎯 Core Focus
* **📉 Cloud-Exit Strategy (FinOps):** Migrating workloads to **Bare Metal** and VPS where the numbers justify it.
* **🛡️ Edge Security & DevSecOps:** Enforcing **OWASP CRS** rules at the ingress with custom **Caddy + Coraza WAF** builds, and hardening hosts mapped to **NIST 800-53**.
* **📊 Sovereign Data Platforms:** Deploying multi-tenant ELT pipelines to reduce proprietary SaaS sprawl.

### 📂 Featured Public Engineering

Most of my client work is confidential and stays private. These public repositories show how I work:

* **[Hardened](https://github.com/Developmi/hardened):** Ansible hardening suite for bare metal and VPS on Debian 12 and Ubuntu 22.04. Mapped to NIST 800-53 and CIS, with a Tailscale private mesh, CrowdSec and SOPS + age secrets.
* **[Caddy WAF](https://github.com/Developmi/caddy-waf):** Production-hardened Docker image with Caddy + Coraza WAF + OWASP CRS v4.29.0. Cosign-signed, SLSA provenance, Trivy scanning, non-root (UID 1337), multi-arch amd64/arm64.
* **[Caddy WAF UI](https://github.com/Developmi/caddy-waf-ui):** Management UI for caddy-waf. Go standard library only, no runtime dependencies.
* **[Multitenant ELT](https://github.com/Developmi/multitenant-elt):** Multi-tenant ELT pipeline with dlt and dbt Core, per-tenant schema isolation on PostgreSQL and Metabase dashboards.
* **[SOS Animales](https://github.com/Developmi/sos-animales):** Open-data platform for animal welfare in Colombia. FastAPI, PostgreSQL, Valkey and HTMX.
* **[PassiveSentry](https://github.com/Developmi/passive-sentry):** Structure and documentation of a passive OSINT security auditing project, mapped to OWASP Top 10 2025. The working code is not published.
